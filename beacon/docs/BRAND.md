# Beacon identity

Beacon uses a neutral signal mark, condensed wordmark, dark gray surfaces, and one red focal action. Completed states are white. The app's functional interface is native React Native UI; the logo is a static bundled asset.

## Generated icon

File: `apps/mobile/assets/beacon-icon.png`.

Created with OpenAI image generation from this design brief: a simple, memorable white beacon/signal symbol on a near-black square, geometric and high contrast, readable at small mobile icon sizes, no wording, gradients, shadows, extra colors, or decorative details. The mark should communicate a point of origin and an outward signal without resembling an official emergency-services seal.

The neutral icon is used for the launcher and splash. A small vector mark in the shared UI remains neutral beside the red SOS action. Colors, typography, interaction patterns, and accessibility decisions are documented in [DESIGN.md](DESIGN.md).

## Map attribution
