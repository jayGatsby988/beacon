# Beacon

Community help when connectivity disappears. A foreground-first iOS/Android app with signed, persistent, store-and-forward Bluetooth requests and explicit volunteer assistance confirmation.

This repository is an AI-assisted mock-hackathon/research build. GitHub account rotation is a workflow exercise and is not evidence of independent human authorship. Hardware and deployment claims are recorded only after verification.

## Work in progress

The interface, native Bluetooth transport, and protocol are being built in parallel. See docs/WORKSTREAMS.md. Beacon supplements community coordination; it does not automatically contact emergency services or guarantee help.
