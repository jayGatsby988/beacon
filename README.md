# Beacon

An offline community assistance app for iPhone and Android. Send an SOS, carry signed requests between participating phones over Bluetooth, and retain the last confirmed volunteer status when connections disappear.

The application, backend, build instructions, and verification records are in **[beacon/](beacon/README.md)**.

This is an AI-assisted research/mock-hackathon implementation. Three authorized GitHub accounts alternate meaningful integration commits as a workflow exercise; they do not represent three independent human authors. Beacon does not contact emergency services or guarantee that assistance will arrive.
